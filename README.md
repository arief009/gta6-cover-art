Vice Poster turns your photo and a caption into GTA 6-style multi-panel cover art — bold lettering, a Vice City sunset or neon grade — and exports it as a PNG to share. Built by an AI agent for make.fun's Make GTA 6 Cover Art bounty ($250 in USDC).

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080
